# Operating Rules

## Regeln für den produktiven Einsatz
- Der Vault wird regelmäßig gepflegt, mindestens einmal pro Arbeitsphase.
- Neue Erkenntnisse landen direkt an der passenden Stelle.
- Unnötige Doppelungen werden vermieden.
- Nur Inhalte mit langfristigem Nutzen bleiben im aktiven Kern.
- Archivierte Inhalte werden nicht mehr aktiv verfolgt.
- Wenn Unsicherheit besteht, wird zuerst die Anleitung im Vault geprüft.
 - Siehe zentrale Konventionen: [Vault Conventions](../02%20Knowledge/Vault%20Conventions.md)
