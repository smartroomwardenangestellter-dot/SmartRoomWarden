# Problem Solving Log

## Format
- Problem
- Ursache
- Lösung
- Verifikation
- Folgeaufgabe

## Beispiele
- Fehlender Import in der Testumgebung
  - Ursache: Abhängigkeit nicht im Projekt-Environment installiert
  - Lösung: Bibliothek im venv installieren und mit dem richtigen Interpreter testen
  - Verifikation: Tests liefen erfolgreich durch
