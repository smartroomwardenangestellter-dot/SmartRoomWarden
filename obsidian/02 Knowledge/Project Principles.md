# Project Principles

## Entwicklungsprinzipien
- Klare Trennung von Konfiguration, Business-Logik und Infrastruktur
- Keine Secrets im Quellcode
- Tests sind ein Teil der Produktqualität, nicht nur ein Zusatz
- Dokumentation wird parallel zur Entwicklung gepflegt
- Refactoring erfolgt bewusst und nachvollziehbar

## Wissensmanagement-Prinzipien
- Erkenntnisse werden nicht nur gespeichert, sondern aktiv genutzt
- Jeder relevante Fehler bekommt eine nachvollziehbare Lösung
- Entscheidungen werden mit Kontext und Begründung dokumentiert
- Der Vault ist ein lebendiges Arbeitswerkzeug, kein statisches Archiv
